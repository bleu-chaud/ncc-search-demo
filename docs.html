Exact match voor product-/serienummers

Het veld num_typos wordt per zoekveld ingesteld. De eerste waarde hoort bij het eerste query_by veld, etc.

Hoe het werkt

  • model, brand_name, ean, sap_code → 0 typo's. Zoeken op DS-2CD2346G2 vindt alleen exacte matches. Een typo als DS-2CD2346G3 geeft geen resultaat op het model-veld.
  • title, usps, summary → 1-2 typo's. Zoeken op dome camra vindt alsnog "Dome Camera" producten.

Ranking: boost_score

De ranking vervangt 22 Elasticsearch Painless scripts met een enkele optelsom, berekend bij het indexeren:

// Berekend bij import (mock.php / export module)
$boost = 0;
if ($product['recommended']) $boost += 4;    // ES: factor 4x
if ($product['sale'])        $boost += 2;    // ES: factor 2x
if ($product['eol'])         $boost -= 5;    // ES: factor 0.2x
foreach ($product['categories'] as $catId) {   // ES: 14 scripts
    $boost += $categoryBoosts[$catId] ?? 0;
}
foreach ($product['properties'] as $propId) {   // ES: 5 scripts
    $boost += $propertyBoosts[$propId] ?? 0;
}

Sort expressie

// Met zoekterm:
sort_by: '_text_match(buckets:10):desc, boost_score:desc, sale_count:desc'

// Zonder zoekterm (browse):
sort_by: 'boost_score:desc, sale_count:desc'

Stap 1: Groepeer resultaten in 10 relevantie-buckets. Stap 2: Binnen elke bucket, sorteer op boost_score. Stap 3: Bij gelijke boost_score, sorteer op verkoopaantallen.

Nul-resultaten fallback

Als een zoekopdracht 0 resultaten oplevert, toont de UI automatisch aanbevolen producten:

  1. Zoek met de ingevoerde term
  2. Als found === 0, doe een tweede query: q=* met filter_by: recommended:=true
  3. Toon banner: "Geen resultaten gevonden. Bekijk deze aanbevolen producten:"
  4. Toon de top 6 aanbevolen producten gesorteerd op boost_score:desc
Test: zoek op xyznonexistent — je krijgt 6 aanbevolen producten te zien in plaats van een lege pagina.
